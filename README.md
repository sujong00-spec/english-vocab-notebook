# 단어 공책

한글 뜻 → 영어 쓰기, 영어 → 한글 뜻 쓰기를 선택하고 **실제 공책에 답을 쓰는** 학원 시험 대비 앱입니다. 기존 받아쓰기 앱과 독립된 저장소이며 음성 받아쓰기나 화면 필기는 제공하지 않습니다.

## 실행

Node.js 20 이상, Python 3 필요. 앱 자체는 빌드나 서버 API가 없는 정적 웹입니다.

```sh
npm ci
npm start
```

브라우저에서 http://localhost:4173 접속. 정적 호스팅에서도 동일하게 실행됩니다. `file://` 대신 HTTP(S)를 사용하세요.

## 사용 방법

1. `apple : 사과` 형식으로 한 줄에 한 단어를 입력하거나 사진에서 가져옵니다.
2. OCR의 영어 철자·한글 뜻·줄 순서를 수정하고 **단어장 확인하고 저장**을 누릅니다. 형식이 맞지 않는 줄이 있으면 전체 저장을 막아 누락을 방지합니다.
3. 시험을 시작하면 한글 뜻만 보입니다. 공책에 쓰고 다음 문제로 이동합니다.
4. 마지막 문제를 마쳐야 정답표가 나타납니다. 보호자가 모든 문항을 맞음/틀림으로 채점합니다.
5. 오답만 다시 시험합니다. 반복 시험에서도 정답표는 마지막에 표시됩니다.

단어장·시험 문항 스냅샷·현재 문제·시험 회차·일부 채점 결과는 매 변경 시 localStorage에 저장됩니다. 같은 브라우저와 주소에서 새로고침하면 복원됩니다. 저장이 차단되면 안내합니다. 기기 간 동기화는 없으며 브라우저 데이터 삭제 시 사라집니다. 단어장은 텍스트로 내보낼 수 있습니다. 편집 중인 미저장 입력과 OCR 진행은 복원 대상이 아닙니다.

## 사진 인식

Tesseract.js 5.1.1의 영어+한글 모델을 브라우저에서 실행합니다. 사진을 업로드하는 자체 서버는 없습니다. 최초 인식 시 jsDelivr와 Tesseract 언어 모델 배포 서버에 인터넷 연결이 필요합니다. 모델 다운로드·캐시 동작은 브라우저 환경에 따라 다릅니다.

인식 전 이미지를 최대 긴 변 2600px로 조절하고 회색조·대비를 보정합니다. 단어 번호, 공백, 탭, 콜론·세미콜론, 구분선과 전각 문자 등을 정규화합니다. 영어와 한글 뜻이 같은 줄에 있는 정면 인쇄 단어장을 권장합니다. 여러 열, 필기체, 기울어진 사진은 직접 수정이 필요합니다. 인식 결과를 자동으로 확정하지 않습니다.

## 검증

```sh
npm test
npx playwright install chromium
# 별도 터미널에서 npm start 실행
npm run test:browser
node tests/ocr-live.mjs
```

`CHROMIUM_PATH`로 시스템 Chromium 경로를 지정할 수 있습니다. OCR 실검증은 외부 모델 다운로드가 필요합니다. 일반 브라우저 테스트는 OCR 엔진만 모의 처리하고 실제 이미지 전처리·결과 검토·저장 흐름을 확인합니다. 생성한 스크린샷은 `test-results/`에 저장됩니다.

상태 복원/잘못된 저장 데이터/마지막 문제까지 정답 비공개/보호자 채점/오답 반복/태블릿 가로·세로와 모바일 가로 넘침을 검증합니다. 실제 학생 단어장 사진으로 측정한 인식 정확도 수치는 아직 없습니다.

실제 엔진으로 생성한 정면 인쇄 샘플 3쌍(apple/사과, school/학교, friend/친구)의 영어·한글 내용 인식과 저장을 확인했습니다. 콜론이 세미콜론으로 인식된 경우도 처리합니다. 이 결과는 실물 사진 정확도를 뜻하지 않습니다.

## 학습 흐름 개선

- 전체/오답/다음날 복습마다 회차, 시작·채점 완료 시각, 문항 스냅샷, 정오답을 보존합니다. 마지막 문항까지 채점해야 완료 기록을 남기며, 같은 시험의 채점을 수정하면 기록 하나를 갱신합니다. 미완료 시험을 중단해도 과거 완료 기록은 유지합니다.
- 최초 전체 시험의 점수와 회차별 상세 정답·오답, 단어별 누적 오답 횟수를 확인하고 JSON으로 내보낼 수 있습니다. 다른 단어장을 저장해도 이전 시험 기록은 남습니다. 기존 단어의 영어·한글 뜻이 같으면 품사/설명 수정 후에도 학습 기록 연결을 유지합니다. 영어 또는 뜻 자체를 바꾸면 새 단어로 취급합니다.
- 오답 시험에는 원래 단어장 번호를 표시합니다. 공책의 새 줄에 회차와 이번 문제 번호를 적도록 안내하고 정답표도 이번 회차 순서로 표시합니다.
- 전체 시험과 오답 시험 모두 순서 섞기를 선택할 수 있습니다. 시험 시작 시에만 섞으며 새로고침해도 문항 순서를 유지합니다.
- 지난 날짜에 완료한 기록이 있는 현재 단어를 ‘오늘 복습’으로 모읍니다. 날짜는 기기의 현지 달력 기준입니다. 단순한 하루 단위 복습이며 FSRS 예측 모델은 도입하지 않았습니다. 당일 반복 정답은 ‘다음날 확인 필요’, 마지막 오답 이후 서로 다른 두 날짜에 맞힌 단어는 ‘다른 날 정답 확인’으로 표시합니다. 이 표시는 학습 효과를 보증하는 점수가 아닙니다.
- `see : 보다 | 동사 | 눈으로 보이다`처럼 품사·구분 설명을 넣을 수 있습니다. `watch : 보다 | 동사 | 주의 깊게 보다`와 구별할 수 있습니다. 뜻·품사·설명에는 영어를 넣을 수 없어 시험 화면에 영어 답이 노출되지 않습니다. 기존 기본 형식도 지원합니다.
- 사진 원본을 크게 열 수 있고 태블릿 가로 화면에서는 입력란과 나란히 비교합니다. 모든 OCR 줄을 확인 표시해야 저장됩니다. 수정한 줄은 다시 확인해야 하며, 잘못된 형식과 낮은 인식 신뢰도(제공되는 경우 85 미만)를 표시합니다. OCR이 아예 누락한 단어는 원본을 보고 직접 추가해야 합니다.
- 저장 형식은 v2이며 같은 저장 키의 v1 진행 상태를 자동 이전합니다. 원본 사진·OCR 진행·미저장 편집은 기기 저장소에 기록하지 않습니다. 학습 기록을 포함하므로 저장 용량이 부족하면 안내하며 자동 삭제하지 않습니다.

실사용 관찰 절차와 참고 자료는 [LEARNING_REVIEW.md](LEARNING_REVIEW.md)에 있습니다.

v1에 남아 있는 완료 시험도 기록으로 이전합니다. v1에는 시험 날짜가 없으므로 ‘시험 일시 미상’으로 표시하며 복습 날짜 계산은 이전한 날부터 적용합니다. `(동) 보다`, `[명사] 사과` 같은 한글 품사 접두어와 `3월` 같은 숫자로 시작하는 뜻도 인식합니다.

## 양방향 시험과 영어 발음

시험 준비의 ‘시험 방향’에서 **한글 뜻 → 영어 쓰기 / 영어 → 한글 뜻 쓰기**를 선택합니다. 시험 중 방향은 고정되며 오답 재시험과 새로고침 복원에도 유지됩니다. 선택 방향별 첫 시험 점수·누적 오답·다음날 복습·다른 날 정답 확인을 구분하고 회차별 기록에 방향을 표시합니다.

- 한글 → 영어: 한글 뜻과 한글 구분 설명으로 출제하며 영어 답과 발음은 마지막 정답표에서만 제공합니다.
- 영어 → 한글: 영어만 출제하고 한글 뜻·품사·구분 설명을 숨깁니다. ‘영어 발음 듣기’를 누르면 해당 영어를 읽습니다. 마지막 정답표는 한글 뜻을 강조하며 보호자가 학원에서 인정하는 뜻에 맞춰 채점합니다.
- 정답표에서는 두 방향 모두 문항별 영어 발음을 들을 수 있습니다.

발음은 브라우저의 SpeechSynthesis와 기기의 영어 음성을 사용합니다. 자동 재생하지 않으며 중복 재생·문제 전환·화면 이탈 시 이전 발음을 중지합니다. 음성 미지원 또는 재생 실패 시 안내하며 시험은 계속할 수 있습니다. 음질·발음·네트워크 필요 여부는 기기/운영체제의 설치된 음성에 따라 다릅니다. 자동 테스트는 음성 호출·언어·중지·오류 처리를 검증하며 실제 태블릿의 소리 출력은 별도 확인이 필요합니다.

저장 형식 v3은 기존 v1/v2 단어장과 시험 진행·기록을 보존하고 이전 시험은 한글 → 영어 방향으로 이전합니다.

배포된 [테스트 페이지](https://english-vocab-notebook-test.constantcapybara1.chatgpt.site)에서 같은 ChatGPT 계정으로 로그인해 사용할 수 있습니다.

## 크롬 실행과 홈 화면 설치 (PWA)

같은 테스트 주소를 브라우저에서 바로 사용하거나 홈 화면/앱 목록에 설치해 별도 창으로 열 수 있습니다. 앱스토어용 APK/IPA 배포가 아닌 웹 앱 설치 방식입니다. 설치 조건이 충족되면 화면의 ‘앱으로 설치’ 버튼이 나타납니다. 버튼이 없으면 ‘설치 방법’ 안내와 브라우저 메뉴를 사용하세요.

- 안드로이드 Chrome: ⋮ → 앱 설치 또는 홈 화면에 추가
- PC Chrome: 주소창 설치 아이콘 또는 ⋮ → 전송, 저장 및 공유 → 페이지를 앱으로 설치
- iPhone/iPad: Safari → 공유 → 홈 화면에 추가 → ‘웹 앱으로 열기’ 옵션이 있으면 켬 → 추가

[Chrome 공식 안내](https://support.google.com/chrome/answer/9658361?hl=ko), [iPad 공식 안내](https://support.apple.com/guide/ipad/ipad8f1f7a29/ipados). 메뉴 이름은 기기/브라우저 버전에 따라 다릅니다.

처음에는 인터넷에 연결해 같은 ChatGPT 계정으로 로그인하고 앱 파일의 오프라인 준비를 마쳐 주세요. 이후 기본 시험·채점·오답 반복·기록은 오프라인에서도 이용할 수 있습니다. 사진 OCR의 외부 라이브러리/언어 모델과 일부 기기 음성은 인터넷이 필요합니다. 오프라인 기능은 로그인 세션이나 기기 간 기록 동기화를 대신하지 않습니다. 설치 앱과 브라우저의 저장소 공유 여부는 운영체제에 따라 달라질 수 있으므로 기존 기록은 내보낸 뒤 확인하세요.

서비스 워커는 앱 파일만 버전별로 저장하고 외부 OCR 요청이나 사용자 사진을 캐시하지 않습니다. 새 버전은 기존 앱의 모든 창이 닫힌 뒤 적용되어 진행 중인 시험에 서로 다른 버전의 파일이 섞이지 않습니다. 향후 앱 수정 시 `sw.js`의 CACHE 버전도 반드시 변경해야 합니다. 브라우저 데이터/캐시 삭제 시 오프라인 파일과 학습 기록이 사라질 수 있습니다.

CI의 `tests/pwa.mjs`는 실제 서비스 워커와 오프라인 환경에서 최초 재접속·문제 중간 새로고침·양방향 시험·채점·오답·기록을 검증합니다. 설치 UI는 모의 설치 이벤트로 사용자 클릭과 취소 처리를 검사하고 Chromium이 manifest를 해석하는지 확인합니다. 실제 태블릿 홈 화면 설치는 별도 확인이 필요합니다.
